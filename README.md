# TP Deep Learning, SE & IA

Énoncé du TP de prise en main de PyTorch, baseline ResNet18 et data augmentation
sur CIFAR-10.

**Site : <https://bonben.github.io/ensta-tp-deep-learning/>**

Le site est généré avec [MkDocs Material](https://squidfunk.github.io/mkdocs-material/)
à partir du dossier `docs/`, et publié par GitHub Actions à chaque push sur `main`.

Pour le prévisualiser en local :

```bash
pip install -r requirements.txt
mkdocs serve
```

Adapté des labs 1 et 2 du cours
[Efficient Deep Learning](https://github.com/brain-bzh/efficient-deep-learning)
d'IMT Atlantique.
